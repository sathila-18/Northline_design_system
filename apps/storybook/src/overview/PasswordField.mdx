## Accessibility

- The input switches between `type="password"` and `type="text"`. The caret position and value stay.
- The button is always named "Show password". `aria-pressed` carries the state. It is a separate tab stop after the input.
- `autoComplete` defaults to `current-password`. Pass `new-password` when creating one.
- The input has a real `label`. `aria-describedby` points to the helper text, and an error sets `aria-invalid="true"`.
