## Accessibility

- `title` is required. The plot is a group with the role description "chart", named by the title.
- The plot is one tab stop. Left and Right move by category. For horizontal bars, Up and Down do. Home and End go to the ends. Escape hides the tooltip.
- Each step announces the category and every series' value. Stacked bars also announce the total.
- Colour is never the only signal. There is a legend for more than one series, and the tooltip and table name every value.
- The table view is the full screen reader route.
- Bars grow in when they appear. With reduced motion they don't animate.
