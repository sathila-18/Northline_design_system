## Statuses

There are three statuses: loading, success and error. The result's label is announced.

<StoryWithCode of={Stories.Statuses} />

## With a value

With `value`, the arc length shows how much is done and the ring doesn't turn.

<StoryWithCode of={Stories.WithValue} />

## Accessibility

- While loading, it has `role="progressbar"` and a name from `label`. It has `aria-valuenow` only when `value` is set.
- Success and error use `role="status"`, so the change is announced. The caller passes the text through `label`, for example "Upload complete".
- The arc turns continuously. With reduced motion it stays still and the label carries the meaning.
- The arc needs 3 to 1 against the track.
