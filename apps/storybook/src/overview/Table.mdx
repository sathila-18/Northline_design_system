## Accessibility

- It is a real `table` with a `caption`, `thead`, `tbody` and column headers. The first data column can be a row header.
- Sorting and filtering happen from the header cells. Result changes are announced politely, for example "Showing 12 results".
- Select-all reflects the current page and is indeterminate when some rows are selected. The selected count is announced and shown.
- While loading, the table has `aria-busy="true"`.
- A row click is never the only way to act on a row. The row-actions button is always there.
