## Accessibility

- An action menu has `role="menu"` with `menuitem` rows. Up and Down move between rows and wrap. Home and End go to the first and last. Enter or Space activates and closes. A letter jumps to the next row that starts with it.
- A select menu has `role="listbox"` with `option` rows and `aria-selected`. A multiple select adds `aria-multiselectable`. Enter or Space selects. A single select closes on select.
- A filter menu is a non-modal dialog. Tab moves through the header, rows and footer.
- A navigation menu has `role="menu"`, and its rows are links. Enter follows the link.
- Escape closes any menu and returns focus to the trigger. A click outside closes it.
- On open, focus goes to the selected row (select), the first row (action, navigation) or the first field in the header (filter).
- The trigger has `aria-haspopup`, `aria-expanded` and `aria-controls`.
- Dividers between groups are decorative. Labelled groups use `role="group"` with a name.
- Disabled rows are skipped by the arrow keys and announced as unavailable.
