## Accessibility

- It is a `td`. The first meaningful cell in a row can be a row header (`th scope="row"`), so screen readers name the row.
- A row-select checkbox is named "Select" followed by the row name. A value checkbox is named by the row and column.
- The row-actions button is named "Actions for" followed by the row name, with `aria-haspopup="menu"` and `aria-expanded`. Its column stays in place when the table scrolls sideways.
- Truncated text keeps its full text available.
