## Accessibility

- It is a `nav` named "Main" with a list of sections.
- The collapse button is named "Collapse navigation" or "Expand navigation". It has no `aria-expanded`, because the name says what it does.
- From 1280 wide the nav is expanded. Below that it is minimized. The user can toggle it until the window crosses 1280 again.
- Minimized, section names are tooltips and visually hidden labels. Sections with pages open them in a menu. Tree lines show only when expanded.
- The section holding the current page opens by default.
