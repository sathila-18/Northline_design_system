## Accessibility

- `title` is required. The plot is a group with the role description "chart", named by the title.
- The plot is one tab stop. Left and Right, and Up and Down, move between slices. Home and End go to the first and last. Escape hides the tooltip.
- Each slice announces its label, value and share, for example "Gold: 312 members, 26%".
- Colour is never the only signal. The legend, tooltip and table name every value.
- The table view is the full screen reader route.
- Slices sweep in when they appear. With reduced motion they don't animate.
