## Accessibility

- It is decorative by default and hidden from screen readers.
- With `label`, it has `role="img"` and `aria-label`. A screen reader hears the label, for example "Warning".
- It is never focusable. Icon-only controls get their name from the control, not from the icon.
- The registry only allows names that are in the icon font.
