## Accessibility

- It has `role="dialog"` and `aria-modal="true"`. The title labels it and the body text describes it.
- On open, focus goes to the first focusable element in the body. For a confirmation it goes to the primary action, or to Cancel when the primary is destructive.
- Focus is trapped inside. On close, focus returns to the element that opened it.
- Escape and the close button close it. A click on the overlay closes it unless it is a required confirmation (`dismissible={false}`).
- The page behind is inert and doesn't scroll.
- It opens with a fade and slight scale. With reduced motion it only fades.
