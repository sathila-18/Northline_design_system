## Accessibility

- It is a native button. Its name includes the count, for example "Notifications, 3 unread", or "Notifications, new" for the dot. The badge itself is hidden from screen readers.
- When the count changes while the page is open, the page header announces it. This button doesn't.
- Enter or Space opens what it controls.
