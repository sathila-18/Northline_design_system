<StoryWithCode of={Stories.MostSeries} />

Long names are cut with an ellipsis at 240. Values are never cut.

<StoryWithCode of={Stories.LongLabels} />

For stacked bars, a total row sits apart with extra space. Bars use square markers.

<StoryWithCode of={Stories.StackedTotal} />

## Accessibility

- It is never focusable, and never the only place a value lives. The table view has every value.
- When the item changes by keyboard, its text goes into the chart's polite live region, so it is announced.
