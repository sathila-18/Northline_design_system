It is the text part of list items, dialogs, empty states, snackbars, tooltips and cards.

## Accessibility

- The look and the heading level are separate. `type` sets the look. `headingAs` sets the element, so a page can keep a correct heading outline.
- The default element is `p`, because most text blocks are not document headings. Dialogs, side sheets and page headers pass the level they need.
- The description is a `p`. The label renders before the heading, so a screen reader reads the label, heading, then description.
- There is no truncation by default. A parent that cuts lines must make the full text available.
