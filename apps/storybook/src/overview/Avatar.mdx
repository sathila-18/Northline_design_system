## Accessibility

- A photo uses `img` with `alt`. Give the person's name in `alt` when the avatar is the only place the name appears. Use `alt=""` when the name shows next to it.
- Initials and the icon are decorative by default. Pass `alt` to name them, which adds `role="img"` and `aria-label`.
- Initials are at most 2 letters, uppercase. With no name, use the icon instead of empty initials.
- The online dot uses `onlineLabel`, so a screen reader hears, for example, "Member 0042, online". Where presence matters, show the status in text nearby too.
