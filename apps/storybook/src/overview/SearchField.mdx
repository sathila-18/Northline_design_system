## Accessibility

- It is a search input (role `searchbox`). The field adds no landmark. The page or toolbar wraps it in `search` when it searches the page or a table. A menu header doesn't.
- Enter calls `onSearch`. When there is text, Escape clears it and calls `onClear`, so a surrounding menu stays open. When empty, Escape passes on.
- The clear button is named "Clear search". After clearing, focus returns to the input.
- The results region announces results that change while typing. The field doesn't.
