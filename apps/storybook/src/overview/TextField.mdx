## Accessibility

- It is a native `input` with a real `label`, the floating label, so the name never depends on the placeholder.
- `aria-describedby` points to the helper text. An error sets `aria-invalid="true"`. `required` adds `aria-required` and a marker in the label.
- A new error is announced through a polite live region in the helper area.
- The focus ring shows whenever the input has focus.
- The label floats with a short animation. With reduced motion it jumps.
- A trailing icon is hidden from screen readers. An icon that does something is a button in the trailing slot.
