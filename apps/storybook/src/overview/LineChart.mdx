## Accessibility

- `title` is required. The plot is a group with the role description "chart", named by the title.
- The plot is one tab stop. Left and Right move by time step. Home and End go to the first and last. Escape hides the tooltip.
- Each step announces the date and every series' value.
- Colour is never the only signal. Each series has its own marker shape, there is a legend for more than one series, and the tooltip and table name every value.
- The table view is the full screen reader route.
- Lines draw in when they appear. With reduced motion they don't animate.
