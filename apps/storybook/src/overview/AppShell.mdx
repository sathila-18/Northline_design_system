## Accessibility

- The nav slot is wrapped in `nav` only when the nav doesn't render its own. The side nav does. The header slot sits in `header` and the content in `main`.
- A skip link is the first tab stop. It moves focus to `main`.
- Only the content scrolls. The scrolling content is focusable by keyboard, so keyboard users can scroll it, and it shows the inside focus ring.
- The layout doesn't shift when the nav changes width.
