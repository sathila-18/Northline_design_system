## Accessibility

- It uses a native file input, visually hidden. The button and a click on the card open it. The card is also a drop target.
- The input has a label, "Upload a file", and `aria-describedby` points at the hint with the types and size.
- While uploading, the progress bar has a name, for example "Uploading reward-image.png".
- Completion and errors are announced through a polite live region in the component.
- After delete or cancel, focus returns to the choose button.
- It takes one file at a time.
